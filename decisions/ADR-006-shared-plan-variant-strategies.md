# ADR-006: Три композиционные стратегии из общего плана

- **Статус:** принято; полнота матрицы заблокирована
- **Дата:** 2026-09-26

## Контекст

A/B/C должны сохранять одну narrative meaning и source facts, но показывать содержимое в разных композициях.

## Решение

Worker создаёт общий DeckPlan. Generation выбирает вариантные layout/composition strategies A (сбалансированная), B (просторная/визуальная), C (плотная/ориентированная на evidence). Факты не меняются ради композиционного label.

## Последствия

Если шаблон не имеет трёх безопасно различимых стратегий, missing variant withheld. Текущая case matrix 6/9 и остаётся BLOCKED.
