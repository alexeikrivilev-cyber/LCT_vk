# Private PPTX inspection protocol

This component is a private, replaceable evidence adapter used by the Template Compiler. Its versioned JSON observations are not `TemplateIR`, a public API, or an agreed external schema.

Running it requires Python 3.12 with only the Python standard library. Set `LCT_PYTHON` to an absolute executable path when the local Python launcher is not usable. On Windows the adapter probes registered Python 3.12 launcher targets; on POSIX it checks `python3`. The Python files ship alongside daemon build output; managed Python provisioning is not implemented.

Run `pnpm build` and then the local timing check with `node apps/daemon/benchmark-python-inspector.mjs`; it uses the compiled adapter. It reports the first call (including interpreter discovery) and seven repeats for three generated fixtures; every measurement starts a new short-lived Python process.

The inspector is read-only. Provisional limits: 64 MiB source file and individual ZIP part, 4,096 archive members, 256 MiB total declared expanded content and XML bytes actually read, 30 seconds per child process, 8 MiB stdout, and 32 KiB retained stderr. The expanded-size cap is four times the existing per-file upload ceiling. XML members are consumed with 64 KiB reads so decompressor output stays bounded independently of central-directory sizes. ZIP stored and DEFLATE parts are supported; BZIP2/LZMA and other compression methods fail closed because Python's readers can expand their chunks before parser-side byte caps apply. These are fail-closed engineering limits pending product policy.

The private observation preserves placeholder index/type and presentation slide order, raw and resolved geometry with provenance, direct text/style facts, parent/source ordering, relationship type/target/mode and normalized internal target parts, slide/layout/master metadata and relationships, theme color/font names, notes/media part inventories, unsupported detail and parser warnings. The input path is excluded. Placeholder geometry inherited from a master is included only where the existing layout inspection records a raw matching master placeholder; style cascade and full theme semantics are not resolved. Unsupported OOXML remains only inventoried. DTD-bearing XML and unsafe/duplicate ZIP members are rejected. External relationships are preserved as observations and never dereferenced. The envelope and all field names remain private and replaceable; they are evidence for mapping work, not a canonical model.
