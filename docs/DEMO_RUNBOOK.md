# Demo runbook — 7 минут (не репетирован)

Этот сценарий описывает порядок показа, но не является подтверждением семиминутного end-to-end timing. 12-slide smoke занял 322.635 s в fake режиме. Перед показом нужен короткий rehearsal с выбранным шаблоном. Для fallback допустим локальный fake endpoint; он не доказывает качество модели. Не использовать AIOS как happy path: последний held-out run остановился до генерации.

| Время | Действие | Что видит жюри | Ожидаемое состояние | Fallback |
|---|---|---|---|---|
| 0:00–0:40 | Открыть подготовленный проект; показать этапы и загрузить выбранный PPTX-шаблон, если он ещё не загружен | Файл и карточка шаблона | Файл загружен | Открыть заранее созданный проект и объяснить, что повторный upload не нужен |
| 0:40–1:30 | Нажать «Анализировать шаблон» | Слайды, макеты и структурный профиль | «Шаблон изучен» | При сбое показать сохранённый профиль; не называть его live inference |
| 1:30–2:00 | Добавить Markdown/CSV/JSON/TXT исходные материалы и заполнить бриф | Список распознанных исходников | Материалы распознаны, бриф заполнен | Использовать подготовленный synthetic файл с пометкой «демо-данные» |
| 2:00–3:00 | Нажать «Сформировать план», затем просмотреть порядок и заголовки | План до верстки | План сохранён и проходит схему | Использовать сохранённый fake plan; показать отдельно, что Worker/Supervisor live не запускались |
| 3:00–4:30 | Нажать «Создать варианты слайдов» | A/B/C по каждому слайду и предпросмотр | Варианты готовы либо честно withheld | Показать заранее созданные варианты поддержанного шаблона; не скрывать withheld |
| 4:30–5:30 | Открыть «Аудит качества», показать предупреждения, применить доступное безопасное исправление | Проблемы и результат проверки | Audit clean либо явно перечислены findings | Если исправление недоступно, показать причину и не обещать автоматический semantic repair |
| 5:30–7:00 | Выбрать/закрепить вариант и скачать PPTX, затем PDF/HTML | Редактируемый PPTX и варианты просмотра | Файл скачан; PPTX структурно reopened тестом | При недоступном формате показать его тесты/ограничения; визуальную точность в Office не заявлять |

## Демонстрационные ограничения

- Для устойчивого flow сейчас выбирать шаблон с прошедшей локальной A/B/C qualification. WorkSpace не прошёл; AIOS held-out тоже заблокирован.
- Полный unknown-template E2E пока не подтверждён. Поэтому требование показа неизвестного шаблона остаётся release blocker, несмотря на этот сценарий.
- PDF строится через растровый approximate preview; HTML — отдельный формат просмотра. Ни один из них не является визуально тождественным PowerPoint.
- При недоступности live inference использовать локальную fake-конфигурацию из `.env.example` и прямо обозначать её как имитацию.
- Перед live demo выполнить ограниченную qualification и rehearsal; этот документ не заменяет их.
