# Квалификация шаблонов

Preview помечает геометрический выход как видимое предупреждение об унаследованной оболочке только при уникальном совпадении измеренной геометрии с объектом выбранного source slide/layout/master и для класса `GENERATED_OBJECT_OUT_OF_BOUNDS`. Совпадение имени фигуры не требуется, поскольку renderer может переименовать её при клонировании; несколько совпавших геометрий и другие error-классы остаются блокирующими. Структурный selector выводит closing-role только из общей геометрии нижнего ряда небольших визуальных якорей, близко привязанных текстовых меток и отдельного квадратного callout; closing donor допустим лишь для summary intent. Для replaceable body-like областей ранжирование учитывает полноту использованных зон, площадь свободных зон и безопасные визуальные slots. Маленький пустой маркер удаляется вместе с незадействованной строкой лишь при уникальной геометрической привязке к ней; выбранные строки и явно сохранённый chrome остаются.

Квалификационный результат привязывается к hash шаблона, ContentIR/brief/DeckPlan и к версии программных prompt/config. Generic selector должен работать по структуре, без organizer-specific имён или захардкоженных индексов.

Exemplar selector сохраняет полноэкранный image shell только при почти точном покрытии холста без поворота, трёх или более независимых редактируемых текстовых объектах поверх него и сходном 16×9 sRGB media fingerprint на минимум 80% слайдов той же layout family. Полноэкранная фотография с отличающимся fingerprint остаётся source-specific даже в повторяющейся layout family. Классификация не выполняет OCR растрового изображения; previews целевого шаблона остаются необходимой проверкой на запечённый в изображение текст.

Семантический profiler может переиспользовать профиль для точных повторяющихся морфологий только с one-to-one ID mapping, confidence представителя не ниже 0.85 и уже подтверждённой replaceable-разметкой изменённого текста. Профиль ограничивается confidence 0.8; неоднозначные и низкоуверенные слайды идут в отдельный inference. Синтетическая проверка покрывает геометрический выброс, неоднозначный текст и low-confidence family fallback.

Повторный профиль не переносит semantic archetype представителя на другой текст: selector заново оценивает archetype по структуре целевого слайда. Повторные профили не декларируют content modes и не создают новых planning-budget families; planner использует отдельно профилированного представителя. Внутренние provenance reason codes запрещены для ответа модели. Общий cache хранит проверенные semantic-профили, но не детерминированный fallback после временной ошибки inference. Raw-media fingerprint fail-closes для вложенного picture или unresolved group geometry, нестандартной picture mask, shape effect или 3D style, а также для crop, flip, tile fill, ненулевого fill rectangle, rotWithShape или вложенного picture effect, если этот transform не учтён при его вычислении.

Verified organizer-matrix facts остаются в [CASE_REQUIREMENTS.md](../compliance/CASE_REQUIREMENTS.md): на последней versioned organizer matrix получено 6/9 variants; WorkSpace остановил все три варианта, а held-out AIOS дошёл до планирования, но не прошёл distinctness gate. Это BLOCKED, не PASS. Отдельный overnight product E2E от 2026-09-29 на реальных WorkSpace и held-out шаблонах прошёл fake-only: по 10 slides, A/B/C 30/30, deterministic/contextual audits, editable PPTX, PDF/HTML и unchanged source; VK Education прошёл reduced 3-slide smoke. Это не заменяет live inference, organizer-matrix qualification или PowerPoint visual review. Contact sheets и ignored qualification artifacts доступны для визуальной проверки.
