# Offline visual quality review v2

Проверка выполнена на ветке `generation-quality`, без live inference. Визуальные выводы основаны на свежих PNG и парах «исходный донор — A/B/C», созданных 2026-09-29 после bounded quality-итерации.

## Решение о LLM design director

**Рекомендация: NO, сейчас не внедрять.** Свежие артефакты показывают остаточную проблему в классификации и распределении безопасных геометрических зон: модель выбора не устранит неверную привязку фигуры к body region или fallback при неподходящей структуре.

Если heuristics перестанут быть узким местом после исправления карты зон, ограниченный дизайн-контракт может выглядеть так:

- **Вход:** ID безопасных кандидатов, компактные признаки структуры (число/площадь зон, занятость, шрифтовая иерархия, визуальные якоря) и intent слайда.
- **Выход:** по одному ID кандидата для A/B/C.
- **Ограничения:** строгая JSON-схема, один вызов на деку, кэш по hash входа, детерминированная проверка всех трёх ID и fallback на текущий selector.
- **Оценка:** ожидаемый выигрыш умеренный и пока не измерен; дополнительная задержка одного запроса оценивается примерно в 0,3–0,8 секунды на деку. Это оценка проектирования, не измерение прогона.

## Свежая offline-квалификация

Все прогоны использовали `offline-fake-planner`; `networkRequests=0`, `blockedExternalAttempts=0`, source-template hash остался неизменным, raster-only слайдов нет. Generation time / total time: Workspace 29,7 / 64,9 с (10 слайдов); Heldout 10,1 / 49,6 с (10); Education 46,9 / 137,6 с (5 из 55). Новый вызов модели на слайд не добавлялся, число fake semantic requests осталось на уровне предыдущего прогона: 18 / 8 / 31.

Contact sheets и manifests находятся в игнорируемом каталоге `.lct/quality-review/v3-after-*`. Статус этой bounded итерации — **PARTIAL** из-за видимого недоиспользования отдельных карточек Workspace и fallback последнего слайда Education, хотя оболочка, редактируемый текст, экспорт и A/B/C прошли offline qualification.

## Проверки

- Целевые регрессии полноты body regions, closing topology и маркеров: 3/3 PASS; preview-layout evidence: 6/6 PASS.
- Daemon typecheck, web production build, daemon production build, docs check, presentation boundary check, ручной hardcode audit и `git diff --check`: PASS.
- Полный suite: **350/351**. Один тест `renderer-measured overflow retries only with qualified deck-distinct compositions` не дождался `run-manifest.json` после того, как persisted state уже стал `completed` (ENOENT). Тот же тест отдельно прошёл 1/1; код generation lifecycle не входит в этот diff. Это узкое окно между записью terminal state и последующей записью sidecar при параллельной нагрузке, а не ошибка визуальной квалификации. Полный suite не перезапускался.
- Верхнеуровневый `corepack pnpm build` встретил несовпадение CLI внутри package script (глобальный pnpm 11.19.0 вместо закреплённой версии). Две составные сборки прошли напрямую через закреплённый CLI: `corepack pnpm --filter @lct/web run build` и `corepack pnpm --filter @lct/daemon run build`.
