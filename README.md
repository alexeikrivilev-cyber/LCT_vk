# Прототип LCT для GitHub Pages

Это статическая интерактивная витрина интерфейса LCT. Она показывает демонстрационный сценарий: выбор шаблона, добавление материалов, план презентации, переключение композиций A/B/C и блок проверки.

## Открыть локально

Откройте `index.html` в современном браузере. Сборка, сервер и установка зависимостей не нужны.

## Границы прототипа

- Все данные и слайды на странице демонстрационные.
- Кнопки не загружают и не читают выбранные файлы.
- Генерация — локальная анимация; API, модель и внешние сервисы не вызываются.
- Кнопки PPTX/PDF/HTML показывают подтверждение, но не создают файлы.
- Возможности продукта описаны в пределах уже реализованного конвейера; прототип не обещает универсальную совместимость или pixel-perfect результат.

## Публикация GitHub Pages

В настройках репозитория откройте **Settings → Pages → Build and deployment**. Выберите **Deploy from a branch**, ветку `gh-pages`, папку `/ (root)` и нажмите **Save**. После публикации прототип будет доступен по адресу `https://alexeikrivilev-cyber.github.io/LCT_vk/`.
